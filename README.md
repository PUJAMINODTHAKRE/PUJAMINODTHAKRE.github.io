# Puja Minodji Thakre — Academic Website

Research-first academic website for **Puja Minodji Thakre**, Mathematics Researcher.

The site is intentionally designed as an academic research profile rather than a generic personal portfolio. The homepage answers four questions quickly: **Who is Puja? What does she research? What evidence of research exists? Where can the work be inspected?**

## Structure

- `index.html` — research-first dashboard / landing page
- `research.html` — detailed research projects and methodology context
- `publications.html` — verified publication record, DOI and BibTeX
- `cv.html` — web-readable academic CV + PDF download
- `contact.html` — email, Google Scholar, ORCID, LinkedIn and GitHub
- `assets/site.css` — design system
- `assets/site.js` — navigation + lightweight Research FAQ assistant
- `assets/puja-portrait.jpeg` — supplied profile photograph
- `assets/Puja_Academic_CV.pdf` — supplied academic CV

## GitHub Pages

This is a static site and requires no server-side code. Upload the contents of this directory to a repository and enable GitHub Pages from the repository's Pages settings.

The FAQ assistant runs locally in the browser; it does not require an API key.
