# Puja Minodji Thakre — Academic Website

A static academic research website for GitHub Pages.

## What is included

- `index.html` — research-oriented landing page
- `research.html` — detailed research directions and published comparative study
- `publications.html` — publication record, DOI, citation and BibTeX
- `cv.html` — complete web-readable academic record
- `assets/styles.css` — responsive visual system
- `assets/app.js` — navigation, theme toggle, filters, copy citation and scroll progress
- `assets/research-map.svg` — custom research identity graphic
- `assets/favicon.svg` — site favicon
- `assets/Puja_Academic_CV.pdf` — current academic CV
- `404.html` — GitHub Pages fallback page
- `.nojekyll` — keeps deployment predictable on GitHub Pages
- `NOTICE.md` — publication/data usage notice

## Deploy on GitHub Pages

Create a public repository named:

```text
PUJAMINODTHAKRE.github.io
```

Upload the contents of this folder to the repository root.

Then open:

`Settings → Pages → Build and deployment → Deploy from a branch`

Select:

```text
Branch: main
Folder: / (root)
```

The site will then be available at the repository's GitHub Pages address.

## Important research note

The website links to the Springer DOI and the public research companion repository. It does not redistribute the publisher-controlled Springer article PDF or patient-level research data.
